# ตารางเรียนนักศึกษา · ตารางสอนอาจารย์ · ตารางห้องเรียน — ค.อ.บ. วิศวกรรมโยธา มทร.ล้านนา

หน้าเว็บ: **https://akharapong.github.io/timetable-tedcv/**

เปิดดูได้ทุกคนโดยไม่ต้องเข้าสู่ระบบ มี 3 มุมมอง:
- ตารางเรียน ปี 1–5
- ตารางสอนรายอาจารย์
- ตารางใช้ห้อง

ลิงก์ตรงไปแต่ละมุมมอง (ส่งเข้ากลุ่ม LINE ได้):
- `…/#year=1` ถึง `…/#year=5`
- `…/#teacher=อลงกต` (ใส่ชื่ออาจารย์)
- `…/#room=ยธ.1-202` (ใส่ชื่อห้อง)

> ข้อมูลอ้างอิงระบบทะเบียน reg.rmutl.ac.th หากไม่ตรงกัน ให้ยึดระบบทะเบียนเป็นหลัก

## ไฟล์ใน repository
| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | หน้าเว็บทั้งหน้า (ข้อมูลตารางฝังอยู่ในไฟล์) |
| `files/*.xlsx` | ไฟล์ Excel สำหรับดาวน์โหลด (ตารางเรียน / ตารางสอน / ตารางห้อง) สร้างจากข้อมูลชุดเดียวกับเว็บ |

## วิธีอัปเดต (สำหรับผู้ดูแล)
หน้าเว็บสร้างจากสคริปต์ในโฟลเดอร์ `ตารางสอน 2-2569/_scripts/` บนเครื่องผู้ดูแล

1. สร้างข้อมูลใหม่ ใช้ไฟล์ตารางสอนอาจารย์ที่ดาวน์โหลดจากระบบทะเบียน (RT003)
   ```
   python3 build_data.py ../TimeTable….xlsx
   ```
2. สร้างหน้าเว็บและไฟล์ Excel (เรียก `build_xlsx.py` ให้เอง) ได้ `../web/index.html` และ `../web/files/`
   ```
   python3 build_web.py
   ```
3. คัดลอกไฟล์จาก `web/` มาแทนไฟล์ใน repository แล้ว commit ลง branch `main`
4. GitHub Pages จะอัปเดตเองภายใน 1–2 นาที ลิงก์เดิมไม่เปลี่ยน

รายละเอียดการจัดตารางทั้งหมดอยู่ใน `README.md` ในโฟลเดอร์ `ตารางสอน 2-2569`
